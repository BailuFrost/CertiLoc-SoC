# uart_rx 模块规格

> RTL：`rtl/comm/uart_rx.v`  
> 状态：接口和周期行为已冻结；WaveDrom SVG 因本机缺少规定版本渲染器而未生成。

## 1. 功能

`uart_rx` 在100 MHz系统时钟下接收115200 bit/s、8N1串行字符。异步输入先经两级触发器同步，再按“半位确认起始位、整位间隔采样后续位”的规则恢复字节。

## 2. 参数和接口

| 名称 | 方向 | 位宽 | 语义 |
|---|---|---:|---|
| `C_CLKS_PER_BIT` | 参数 | — | 数据位与停止位采样间隔，阶段1固定为868 |
| `C_HALF_BIT_CLKS` | 参数 | — | 起始位中心确认间隔，阶段1固定为434 |
| `i_clk` | 输入 | 1 | 100 MHz系统时钟 |
| `i_reset` | 输入 | 1 | 同步高有效内部复位 |
| `i_uart_rx` | 输入 | 1 | 异步、空闲为高的串行输入 |
| `i_data_ready` | 输入 | 1 | 下游接受当前字节 |
| `o_data` | 输出 | 8 | 完整接收字节 |
| `o_data_valid` | 输出 | 1 | 字节有效，保持至握手 |
| `o_frame_error` | 输出 | 1 | 停止位错误单周期脉冲 |
| `o_busy` | 输出 | 1 | 正在确认或采样一个字符 |

## 3. 周期行为

- 两级同步后的线路为低且输出槽可用时进入起始位确认。
- 434个时钟后线路仍为低才接受起始位；否则作为假起始返回空闲。
- 随后每隔868个时钟依次采样8个数据位和1个停止位。
- 停止位为高时提交字节；`o_data` 与 `o_data_valid` 保持稳定，直至 `i_data_ready=1` 的上升沿。
- 停止位为低时不提交字节，仅产生一个时钟的 `o_frame_error`。

## 4. 反压与限制

- 输出采用一个字节缓存；下游反压期间不检测新的起始位，以防未消费字节被覆盖。
- 该行为要求包解析器持续消费字节；115200 bit/s下每字节提供约8680个系统时钟的处理预算。
- 当前模块只报告停止位错误；协议超时、CRC与重同步属于T05帧解析器职责。

## 5. 验证案例

- `RX_NOMINAL`：868时钟位周期下恢复 `A5`。
- `RX_CLOCK_MISMATCH`：发送位周期851和885时钟时分别恢复 `96`、`69`。
- `RX_BACKPRESSURE`：下游暂停20个时钟时 `3C` 和有效信号保持不变。
- `RX_BAD_STOP`：低停止位只产生一次错误脉冲，不提交字节。
- `RX_FALSE_START`：100时钟低脉冲被拒绝。
