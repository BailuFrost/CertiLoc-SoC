# uart_tx 模块规格

> RTL：`rtl/comm/uart_tx.v`  
> 状态：接口和周期行为已冻结；WaveDrom SVG 因本机缺少规定版本渲染器而未生成。

## 1. 功能

`uart_tx` 在100 MHz系统时钟下，将一次 `valid/ready` 握手接收的字节编码为115200 bit/s、8N1串行帧。固定整数位周期为868个时钟，名义波特率约为115207.37 bit/s。

## 2. 参数和接口

| 名称 | 方向 | 位宽 | 语义 |
|---|---|---:|---|
| `C_CLKS_PER_BIT` | 参数 | — | 每个串行位的时钟数，阶段1固定为868 |
| `i_clk` | 输入 | 1 | 100 MHz系统时钟 |
| `i_reset` | 输入 | 1 | 同步高有效内部复位 |
| `i_data` | 输入 | 8 | 待发送字节 |
| `i_data_valid` | 输入 | 1 | 输入字节有效 |
| `o_data_ready` | 输出 | 1 | 当前可接收字节 |
| `o_uart_tx` | 输出 | 1 | 空闲为高的串行发送线 |
| `o_busy` | 输出 | 1 | 完整字符发送期间为高 |

## 3. 周期行为

- 仅在上升沿同时满足 `i_data_valid && o_data_ready` 时接收字节。
- 接收后立即装载 `{停止位, i_data, 起始位}`，依次发送1个低起始位、8个最低位优先数据位和1个高停止位。
- 每一位严格保持 `C_CLKS_PER_BIT` 个时钟；完整字符共8680个时钟。
- 帧发送期间 `o_busy=1`、`o_data_ready=0`，任何新的 `i_data_valid` 均不会覆盖当前帧。
- 停止位完成后恢复空闲，下一上升沿可接收新字节。

## 4. 复位与边界

- `i_reset=1` 的上升沿将串行线恢复为高、忙状态清零、入口置为就绪。
- `0x00`、`0xFF` 以及交替位图案必须保持完整的最低位优先顺序。
- 上游必须保持 `i_data` 稳定，直至输入握手完成。

## 5. 验证案例

- `TX_RESET_IDLE`：复位后线路为高、空闲且就绪。
- `TX_BYTE_PATTERNS`：逐位检查 `00`、`FF`、`A5`、`3C`。
- `TX_BIT_LENGTH`：起始、数据和停止位各持续868个时钟。
- `TX_BACKPRESSURE`：忙期间入口始终不就绪。
